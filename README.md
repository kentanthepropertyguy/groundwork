# Ken Property Tools

Singapore property calculators, comparisons and project analysis by
Ken Tan | The Property Guy — **tools.kentanthepropertyguy.com**

Plain HTML, CSS and JavaScript on GitHub Pages. No build step.

**Start here:** [SYSTEM.md](SYSTEM.md) — how the site works, how to update
it, and the rulebook every new tool follows.

Quick reference:

- `data/tools.js` — list of every tool and the homepage goals
- `data/projects/` — one data file per project (prices, PSF, units)
- `assets/css/kpt.css` — the design
- `assets/js/kpt.js` — analytics, WhatsApp, header and footer
- `templates/` — starter pages for new tools
