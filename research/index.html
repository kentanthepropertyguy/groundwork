Research

Understand a home or development, then compare it.

Search an HDB postal code or block, or any Singapore private condo, executive condominium or cluster-housing development, to see what homes like it have sold for, then compare it with another. Browse every development.

  1. Search by development name or postal code.
  2. See what it sold for: HDB resales by flat type, or private resale and new-sale transactions with typical prices per square foot.
  3. Choose “Compare a different project” to get a side-by-side read that matches the same sale type, size band and time window.

Every figure comes from HDB resale registrations or URA private residential transaction records. Where the evidence is thin, the page says so instead of drawing a conclusion. It describes historical transactions and is not personalised advice, a valuation or a forecast.
